FinixDoc-VL API 调用说明
大家好～本次比赛提供 FinixDoc-VL 文档解析 API，供大家在比赛过程中调用使用 🚀

一、FinixDoc-VL 简介
FinixDoc-VL 是我们面向金融文档解析场景发布的视觉语言模型能力，主要用于处理真实业务中常见的票据、理赔材料、保险合同、医疗单据、身份证明、报销凭证等复杂文档。

相比通用 OCR，FinixDoc-VL 更关注金融场景中的结构化解析能力，包括文本识别、版面理解、表格结构还原、阅读顺序恢复，以及 Markdown 等结构化结果输出。

模型针对低质量拍摄件、大尺寸文档、复杂表格、密集文字和金融领域易混字符做了专项优化，目标是在真实业务场景中做到更稳定、更准确、更可验证 ✨

二、API 调用说明
接口地址：

https://finixdocapi.alipay.com/api/finix_doc/call_with_file

调用方式：

POST 表单上传图片，仅支持图片输入，返回对应的 Markdown 解析结果。

三、调用示例
curl -X POST 'https://finixdocapi.alipay.com/api/finix_doc/call_with_file' -F 'userId=finixB2002' -F 'apiKey=F935A5503983FB19F26FA3F00A94EBF9' -F 'fileName=finixdoc.png' -F 'file=@/Users/Downloads/finixdoc.png'

请将示例中的 fileName 和本地图片路径替换为自己的实际文件名和文件路径。

四、参数说明
userId：
参赛调用用户 ID，只能使用指定白名单 ID。

apiKey：
固定值为：
F935A5503983FB19F26FA3F00A94EBF9

fileName：
上传文件名，按实际文件填写，例如 finixdoc.png。

file：
本地图片文件路径，例如：
file=@/path/to/image.png

五、可用 userId
目前仅支持以下 5 个 userId：

finixA1001
finixB2002
finixC3003
finixD4004
finixE5005

请注意：如果传入其他 userId，系统会判定为无权限，无法正常调用。

六、注意事项 ⚠️
由于本次比赛 API 使用统一固定 apiKey，接口侧不做额外账号级鉴权，因此我们对图片输入和模型输出都增加了一定的安全校验机制。

这部分校验会带来额外耗时，所以请求可能会比普通模型调用更慢一些，请大家理解 🙏

另外，请大家合理控制大图切片尺寸。图片或切片过大时，可能导致处理时间过长，甚至请求超时。建议在保证可读性的前提下，对超大页面进行适当切分后再提交。
