## 1. 评分公式与 token 乘子（已拟合验证）

```
FinalScore = 100 · Accuracy · (0.7 + 0.3 · TokenScore)
TokenScore = 1 − used_tokens / 5_000_000
=> 真实准确率 = 官方分 / (100 · 乘子)
```
27b 用 686437 token → 乘子 0.9588，完美拟合（70.9522→74%）。

## 3. ★ 最关键发现：官方评分键【宽松】

由 235b=77 / fixed=79 / star3=76 三锚点解出（每改动效应∈{+1,0,−1}）：
- **ADD 一个逐字为真的选项 = +1**（官方照单全收）
- **REMOVE 一个选项 = −1**（官方算它真，删了白丢分）

fixed 只 +2 不是 +6，就是混进了 3 个 REMOVE。**策略：只加不删。**
推论：官方真答案 ≈「235b 答案 ∪ 漏掉的逐字真选项」。这就是 06_addonly 的构造法。

## 4. 其它已证伪/证实的结论（勿重复踩坑）

- **thinking 模式**：全量 79% vs 无 thinking 80%，噪声带内，无收益。已关。（flag 已验证真生效：enable_thinking=True 出 reasoning_content 796 字符）

- **验证-agent 不可靠**（核题错 4/9）。**只信亲自逐字读原文。**
- **后处理 bug 已修**：`答案：<ABD>` 尖括号致抽取丢字母（answer.py，commit f830b77）。
